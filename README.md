# Keyboard Tester
<img width="1120" height="368" alt="361867399-b4701cd3-3b59-44df-9d5c-31a148b484a2" src="https://github.com/user-attachments/assets/781b7503-5f09-45f6-a11d-3be4dbac9a57" />

این پروژه رو با برنامه Visual Studio، با زبان C# و .NET و با windows form apps به صورت تفریحی ساختمش.

بخاطر محدودیت هایی در KeyDown مثل دکمه Enter که مقدار 13 رو داره، هر دو دکمه Enter یک مقدار رو برمیگردونه.

این بر خلاف بقیه برنامه های تست کننده کیبورد، دکمه Enter سمت راست یا چپ و همینطور بقیه دکمه ها مثل: Ctrl، Shift و Alt رو متمایز میکنه. یعنی همه دکمه های کیبورد قابل تست شدن هستن!

تشکر از برنامه نویس های StackOverflow بخاطر اینکه ی عالمه از مشکل های برنامم رو با جواب های ۱۵ سال پیش حل کردم👌

برای ساختن این برنامه حتی ذره ای از هوش مصنوعی استفاده نکردم

شاید یروز برگشتم و از این کدام استفاده کردم

ی عالمه میخواستم کار روش انجام بدم مثلا دکمه های ترکیبی ویندوز مثل: Ctrl+Shift+ESC یا Alt+Tab رو توش غیر فعال کنم ولی فرصت نشد متاسفانه
